# Mira das Ofertas — Landing Page

Site estático pronto para GitHub Pages.

## Como personalizar
Abra `index.html` e substitua `https://SEU-LINK-AQUI.com` pelo link real do seu grupo (WhatsApp/Telegram).

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Vá em **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)` e salve.

O site é responsivo e não depende de bibliotecas externas.
